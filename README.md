# Universe Explorer — Seabyss

Le simulateur s’ouvre sur https://www.seabyss.com/. Le site est construit à partir de la distribution web d’Universe Explorer et s’utilise au clavier, à la souris ou au toucher.

La photographie SDO/HMI et les états héliocentriques de JPL Horizons sont renouvelés par le workflow observations. Les réponses validées sont enregistrées avec les fichiers du simulateur. Les ressources historiques du lanceur et de l’API conservent leurs chemins.

La branche archive/portal-before-universe-explorer correspond à l’ancien portail de jeux.
