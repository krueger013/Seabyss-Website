Install steps

From download to login

The website no longer offers direct client ZIP downloads. Players should install and use the launcher so updates stay consistent with the manifest.

01

Download

Download the official Seabyss Launcher 0.1.5 installer from GitHub Releases.

02

Run installer

Run the setup package, then open the launcher.

03

Launch the Beta client

The launcher downloads the client listed in the manifest and starts it against the Beta server.

04

Login

Use your Seabyss account in the launcher or game. Seabyss support will never ask for your password.
