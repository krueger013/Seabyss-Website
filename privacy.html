LE PORTAIL DU STUDIO

Confidentialité

Cette page décrit le fonctionnement actuel du portail Seabyss et des jeux intégrés. Mise à jour : 6 novembre 2026.

Explorer sans compte

Le catalogue et les jeux sont accessibles sans créer de compte. Le portail ne propose pas de formulaire de connexion et n’intègre pas d’outil de mesure d’audience ni de publicité.

Tes favoris, sur ton appareil

Quand tu ajoutes un jeu aux favoris, son identifiant est enregistré dans le stockage local de ton navigateur, appelé localStorage. Cette liste n’est pas envoyée à un serveur par le portail. Elle reste disponible dans ce navigateur tant que tu ne la retires pas ou que tu n’effaces pas les données du site.

Ton ambiance, à ton rythme

Le bouton d’ambiance permet de figer ou d’animer le décor. Ton choix est conservé dans ce même stockage local et n’est pas envoyé à un serveur. Le site respecte aussi le réglage de réduction des mouvements de ton appareil.

Les sauvegardes des jeux

Petits Compagnons, Mario’s Ghost et Les Heures Perdues enregistrent leur progression et certains réglages, comme les préférences audio, dans le stockage local du navigateur. Petits Compagnons peut aussi conserver le nom que tu donnes à ton animal. Ces données sont utilisées par le jeu sur ton appareil ; les versions intégrées ne les envoient pas à un service de sauvegarde en ligne.

Le stockage est propre au navigateur et à l’adresse du site. Une partie commencée depuis un fichier local, un autre appareil ou un autre domaine ne se retrouve donc pas automatiquement ici. La navigation privée ou un stockage indisponible peut empêcher de conserver la progression.

Les machines de casino

Le Trésor des Abysses, Le Pacte de Minuit et SUPERNOVA utilisent uniquement un solde fictif. Le solde partagé, les sessions, les bonus et certains réglages sont conservés dans le stockage local de ce navigateur. Aucun dépôt ni retrait d’argent réel n’est proposé. Les pages du casino chargent leurs polices depuis Google Fonts.

Effacer ou conserver tes données

Tu peux retirer individuellement tes favoris depuis le catalogue. Les jeux proposent leurs propres options de nouvelle partie ou de remise à zéro. Petits Compagnons permet également d’exporter et d’importer une sauvegarde ; le fichier exporté est enregistré sur ton appareil.

Les réglages de ton navigateur permettent d’effacer les données du site seabyss.com. Cette opération peut supprimer à la fois les favoris, les parties sauvegardées et les réglages des jeux. Le portail n’utilise pas de cookie pour enregistrer ces préférences.

L’hébergement et les liens

Le site est hébergé par GitHub Pages. GitHub indique que les adresses IP des visiteurs sont enregistrées et conservées à des fins de sécurité. Consulte la documentation de GitHub Pages et la déclaration de confidentialité de GitHub pour les traitements liés à cet hébergement.

Si tu suis un lien vers un autre site, son propre fonctionnement et ses informations de confidentialité s’appliquent. Les jeux actuellement présentés dans le catalogue sont hébergés avec le portail.
